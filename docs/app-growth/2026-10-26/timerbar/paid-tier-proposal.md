# Presenter value decision

Ship the free core clock and existing named presets unchanged. The paid subscription currently adds themes, fonts and colors. The release adds a contextual review request; it does not move existing free functionality behind payment or invent a new price.

A future speaker + Q&A sequence, shareable occasion packs and a room-readable control mode would require implementation and evidence of demand. Named presets and fullscreen display already exist, so simply renaming them as a new paid feature would not add value. Compare completion and upgrade data before changing entitlements. No new paid product was created.
