# Optional cross-promotion decision

Use a voluntary “More apps by asdftq” route in Settings and the existing web catalog. Never insert a game offer during a timer, travel plan or sound check. The three tool apps retain their optional newsletter links and no new post-task advertisement is inserted.

A future finished-task slot could say “A small break? Try SpinHop — one tap, big leaps” and open the verified store URL only on an explicit tap. It would carry no task/user data. Low traffic in the tool apps means a small absolute audience; this is not a growth engine. No impression/click or revenue uplift is claimed.

Native share cards and run codes already exist. Keep game name and store URL on native cards; web sharing explicitly labels demo best and links to the demo. No invented native scores, duplicate rating prompt or cross-app telemetry.
