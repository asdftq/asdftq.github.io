Compatibility

NoBadge 0.1.42 supports Apple Silicon on macOS 26.5.1 and later within macOS 26, and macOS 27. Stable minor and patch updates within these families do not need individual build approval. Directly verified builds are 26.5.1 (25F80), 26.6 (25G72) and 27.0.1 (26A434); this does not mean every build was tested.

NoBadge checks the settings format before changing badges. If Apple changes that format, changes pause and recovery information is kept. Future major versions, beta builds, older macOS versions and Intel Macs need a compatible release.

If an older NoBadge says “This macOS version needs an update” after a macOS upgrade, choose NoBadge → Check for Updates. The message refers to a NoBadge compatibility update. Version 0.1.41 fixes the macOS 27 block and keeps existing settings and activation.

Which badges are supported?

Registered notification badges are supported on both macOS families. Starting with NoBadge 0.1.41, the separate System Settings Dock badge is also supported on macOS 27. It follows Focus, app exceptions and Show badges, and restores before quitting or installing an update. System Settings Dock badges are not supported on macOS 26.

NoBadge changes the Dock badge display; requests and notices inside System Settings remain available. Other custom app-drawn badges may remain. Only supported apps appear in the app list. If a supported settings format changes, NoBadge pauses changes and retains recovery information.

First setup and Full Disk Access

  1. Open the downloaded DMG and drag NoBadge to Applications. Open the copy in Applications, activate with the license key in your purchase receipt, and read the access explanation.
  2. Open System Settings → Privacy & Security → Full Disk Access. Add NoBadge from Applications and enable it.
  3. If macOS asks you to quit and reopen, do so. Return to NoBadge and check access again.
  4. Wait for access and Focus detection to be ready, then continue and start NoBadge.

Full Disk Access is a broad macOS permission. NoBadge uses it to read Focus configuration and update notification badge settings. It does not read messages or documents.

Badges do not return when Focus turns off

Update to NoBadge 0.1.42 or later using Check for Updates. This fixes a timing issue where Focus could turn off during a badge update without triggering restoration. Keep Hide automatically during Focus enabled and choose Any Focus to follow normal Focus on/off changes. No manual restore is needed when Focus ends.

Restore previous settings temporarily shows badges for 15 minutes. If you used it, choose Resume now in General to return to automatic syncing immediately. NoBadge restores your previous badge settings; it does not enable badges you had already disabled yourself.

Focus needs attention

First confirm Full Disk Access is enabled for the installed NoBadge app. Turn on a Focus in macOS once, then use Check Focus again. If detection still fails, open Help & Recovery and export the diagnostic summary for support. Automatic hiding pauses when Focus cannot be read safely.

A badge is still visible

If the System Settings Dock badge remains visible on version 0.1.40, update to 0.1.41 or later. This fixes a preference-storage selection issue and recovers the earlier changes automatically.

Check whether the app is selected in NoBadge → Apps. Selected apps keep their badges. Some apps draw badges themselves and do not respond to the system badge preference.

Menu bar icon hidden?

Open NoBadge from Applications or Spotlight. The settings window opens on the screen you’re using, even if a menu bar manager hides the icon.

Restore settings or remove NoBadge

Choose Restore & Quit from the menu bar, or Help & Recovery → Prepare to uninstall. Wait for restoration to finish before removing the app. After a force quit or crash, reopen NoBadge so it can recover pending settings. If recovery reports a problem, keep the app installed and contact support.

Activate your purchase

Copy the NoBadge license key from your purchase receipt or My Orders and paste it into Activate NoBadge. One purchase allows activation on up to 3 Macs with no subscription or license expiry. Activation and periodic validation require internet; a verified license can work offline for up to 30 days. License data is saved in this Mac’s Keychain.

Moving to another Mac? Open NoBadge → License → Deactivate this Mac to free an activation, then activate the other Mac. If an older order has no key, contact support with your order number; do not pay again.

Downloads and in-app updates

Choose NoBadge → Check for Updates, or open About → Check for Updates. NoBadge checks daily by default; you can turn automatic checks off in About. You choose when to download and install. Updates are signed and notarized, and NoBadge restores badge settings before restarting.

Versions 0.1.35 and earlier do not have an in-app updater. Download the current installer once from My Orders, replace the app in Applications, and activate it. After that, future updates install within NoBadge. The public update archive also requires a purchase license to use the app.

Refunds and purchase support

If NoBadge is not right for you, contact asdftqtq+nobadge@gmail.com within 14 days of purchase to request a full refund. Include your order number and a brief description. Please do not send passwords, private notification content, or payment-card details.

Before removing NoBadge, use Help & Recovery → Prepare to uninstall so your previous badge settings are restored.

Diagnostics

The app previews the exact text before you save a diagnostics file. It contains the app version, OS build, compatibility status, current state and counts. It excludes Focus names, app lists, messages and recovery journal contents.
